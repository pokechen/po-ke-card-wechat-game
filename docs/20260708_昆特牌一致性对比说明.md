# 本项目卡牌 / 领袖 与《巫师三》昆特牌一致性对比说明

> 对比对象：本项目 `js/data/zhangyu_cards.js`（共 199 张卡）与规则实现 `js/core/cards.js`、`js/core/battle.js`；
> 基准：《巫师三：狂猎》内置昆特牌（Gwent，含《血与酒》史凯利杰派系）。
> 生成时间：2026-07-08

---

## 一、结论摘要

本项目在**玩法机制、能力体系、阵线结构、派系框架**上高度还原了巫师三昆特牌，属于「换皮 + 局部改编」的移植：把巫师三的派系、单位、领袖用中国历史人物 / 概念重新命名。

但在以下方面**与原版并不完全一致**：

| 维度 | 是否一致 | 说明 |
|------|:---:|------|
| 三条阵线（近战/远程/攻城） | ✅ 一致 | 疆场/朝堂/文脉，一一对应 |
| 派系数量（5 派系 + 中立） | ✅ 一致 | 结构对应 |
| 能力（技能）种类 | ✅ 一致 | 核心能力齐全，变身 token 已补齐 |
| **领袖数量** | ✅ 已修复 | 遗策复兴（史凯利杰）已收敛为 2 张，全局共 **18 张**，与原版一致 |
| **领袖技能分配** | ✅ 已修复 | 已按派系专属原则重新归位（详见第九节修复记录） |
| 卡牌具体张数 / 战力数值 | ❌ 不一致 | 属重新设计的数值，非 1:1 复刻（有意保留） |

> 注：下方第三~七节为**修复前**的差异分析，第九节为**已执行的修复记录**。

- 天下檄文 = Commander's Horn（中立号角）

- 请辞归隐 = Decoy（诱饵，收回单位）
- 破釜沉舟 = Mardroeme（蘑菇酒）

## 五、能力机制落地情况（部分未落地）

`battle.js` 里实现了完整的昆特牌逻辑，但有几处对应原版的机制在数据里**没有落地**：

1. **Token / 召唤 / 变身体系缺失**
   - `cards.js` 的 `allTokens()` 读取 `DATA.tokens`，但 `zhangyu_cards.js` **未定义 `tokens` 字段**（`DATA.tokens` 为 `undefined`）。
   - 因此 `battle.js` 中的 `transformBerserkers`（变身「Transformed Bear」）、`summonByName("Clan Drummond Shield Maiden")`、`tokenCard("Bovine Defense Force")`、`tokenCard("Hemdall")` 等召唤/变身逻辑**无实际 token 可用**。
   - `ABILITY_LABELS` 中登记的 `Summon Shield Maidens/Avenger/Bovine Defense Force`（对应原版史凯利杰盾女、复仇者、牛群防卫队）在数据里**没有任何卡牌使用**。

2. **奋起（Berserker）链路不完整**
   - 数据中「背水先锋」带 Berserker、中立「破釜沉舟」带 Mardroeme，但因缺少变身 token，`Berserker` 触发后变成的「Transformed Bear」只能回退成硬编码数值（`strength || 8`），并非原版的变身怪物卡。

3. **King Bran 半损天气**
   - 逻辑存在（`recalcScores`），但无对应领袖数据 → 死代码。

4. **奇策阈值差异**
   - 原版中立 Scorch（釜底抽薪对应牌）摧毁全场最强非英雄单位，**不设战力门槛**；本项目 `doScorch` 要求 `effective >= 10` 才可被摧毁。这是规则上的改编。

## 七、其它细节问题（非昆特牌差异，但影响一致性观感）

1. **能力中文名前后不统一**：`cards.js` 的 `ABILITY_LABELS` 把 Medic/Tight Bond/Morale Boost/Muster 译为「举荐/同袍/激励/集结」，而 `zhangyu_cards.js` 的 `abilityDisplayNames` 译为「济世/同盟/振势/集贤」。展示时以数据字段为准，但两处术语不一致。
2. **图片来源混用**：多数卡为 `assets/card-icons/*.webp`，少数（司马懿、曹丕、诸葛亮、周瑜、郭嘉、张飞、司马昭）指向 `cloud://` 云存储，本地资源缺失时可能无法显示。
3. **中立时局「拨云见日」的 `row` 为空**，但 `abilityText` 仍写「压制对应阵线」，文案与实际（清除天气）不符。

## 八、修复建议（如需向原版对齐）

1. **领袖数量**：将遗策复兴（史凯利杰）领袖收敛为 2 张，或明确声明这是「扩展派系设计」。
2. **领袖技能去重与归位**：按派系专属原则重新分配——
   - 北方：清天气、攻城翻倍、摧毁攻城最强、选密雾牌；
   - 尼弗迦德：侦察 3 张、取消主将、选暴雨牌、对手弃牌堆抽牌；
   - 松鼠党：开局抽牌、选凛霜牌、摧毁近战最强、远程翻倍；
   - 怪物：近战翻倍、弃牌堆复活、选任意天气、弃 2 抽 1（或间谍翻倍）；
   - 史凯利杰：洗回弃牌堆、布兰国王半损天气。
3. **补齐 token 数据**：在 `zhangyu_cards.js` 中补 `tokens` 字段（变身、召唤物），让 Berserker/Muster 召唤 / 召唤盾女等能力真正生效，否则删除相关死代码。
4. **统一能力中文译名**，并修正「拨云见日」文案与云存储图片路径。

---

> 备注：以上对比中，领袖技能以数据 `leaderAbility` 英文原文为准；原版技能归属参考《巫师三》官方昆特牌领袖卡资料。若项目定位为「借用昆特牌机制的原创设计」，则上述「不一致」多为有意改编，可据此文档决定保留或对齐。

## 九、修复记录（2026-07-08 已执行）

已按第八节建议完成向原版对齐的修复，改动如下。

### 1. 领袖数量收敛（史凯利杰 4→2）
- 删除遗策复兴多余领袖 `zhangyu-0019 李时珍`、`zhangyu-0020 郑和`。
- 全局领袖数由 20 → **18**，与原版一致（史凯利杰仅 2 张）。
- 卡牌总数 199 → **197**。删除安全：`leadersFor()` 动态返回、选将处 `find(id) || leaders[0]` 兜底。

### 2. 领袖技能按派系专属重新归位
| 派系 | 领袖 | 修复后技能（对齐原版） |
|------|------|------|
| 开国群雄 | 刘邦 | 选「密雾（党争迷局）」牌打出（原 King of Temeria） |
| 开国群雄 | 赵匡胤 | 摧毁对方**文脉/攻城**线最强（≥10）（原 The Steel-Forged，原为摧毁近战，已改） |
| 纵横权谋 | 管仲 | 从对手弃牌堆取回 1 张（原 The Relentless） |
| 纵横权谋 | 曹操 | 选「暴雨（典籍散佚）」牌打出（原 His Imperial Majesty，原为远程翻倍，已改） |
| 百家争鸣 | 墨子 | 己方**朝堂/远程**线翻倍（原 The Beautiful，原为清天气，已改） |
| 草莽星火 | 黄巢 | 弃 2 抽 1（原 Destroyer of Worlds，原为摧毁远程最强，已改） |
| 遗策复兴 | 张居正 | 恶劣时局下己方单位仅损失一半战力（原 King Bran，原为远程翻倍，已改） |

> 修复后：各派系不再出现「一个技能被多派系共享」的错配；史凯利杰恢复为「洗回弃牌堆（司马迁）＋恶劣天气半损（张居正）」。

### 3. 半损天气（布兰国王）落地
- `battle.js/recalcScores` 原判断 `leader.baseName === "King Bran"`（数据中不存在，属死代码）→ 改为基于技能文本 `/half ... strength|lose half|半损|一半战力/`，使张居正的半损被动真正生效。
- `cards.js/translateLeaderAbility` 增加该被动的中文显示与「从对手弃牌堆取回」的显示分支。

### 4. 变身 token 补齐（奋起 + 破釜链路生效）
- `zhangyu_cards.js` 补充 `tokens` 字段，新增 **背水死士（baseName: Transformed Bear，战力 8，传世）**。
- 此前 `DATA.tokens` 未定义导致 `transformBerserkers` 无 token 可用；现「背水先锋(奋起)」被「破釜沉舟(Mardroeme)」触发后可正确变身。
- `battle.js/transformBerserkers` 变身后名称改用 token 的中文 `displayName`。

### 5. 拨云见日修复（发现的额外 Bug）
- **Bug**：拨云见日 `baseName` 实为「特殊卡牌_拨云见日」，而 `isClearWeather` 判断 `=== "拨云见日"`，导致清天气牌**完全失效**（打出后既不清天气也不压制）。
- 修复：`battle.js/isClearWeather` 改为 `/拨云见日|Clear Weather/i.test(baseName)`。
- 同步修正 3 张拨云见日的文案：「时局：压制对应阵线…」→「晴天：清除场上全部时局效果。」

### 6. 术语与资源整理
- 统一能力中文译名：`cards.js/ABILITY_LABELS` 与数据 `abilityDisplayNames` 对齐为「济世 / 同盟 / 振势 / 集贤 / 通才」；`rules.js` 规则文案同步。
- 图片路径：将 7 张 `cloud://` 路径（司马懿、曹丕、郭嘉、司马昭、诸葛亮、周瑜、张飞）统一为 `assets/card-icons/*.webp` 风格。
  > 说明：经核实，卡图实际由 `canvas.js/drawCardImage` 从远程静态托管（`tcloudbaseapp.com`，仅取 `imageUrl` 的文件名）加载，失败时回退 `assets/card-art/` 通用图；故此项仅为**数据整洁**，不影响显示（第七节旧描述据此订正）。

### 7. 验证
- `node` 校验：数据正常加载，各派系领袖数（4/4/4/4/2）与技能显示均正确，token 就位，总卡数 197。
- 跑 90 场跨派系 AI 对局（强制使用各主将、含拨云见日与变身触发），全部正常结束，无异常。
